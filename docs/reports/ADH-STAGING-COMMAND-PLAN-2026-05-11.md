# ADH Staging Command Plan - 2026-05-11

## Purpose

Provide command-level staging options for the local-ready ADH release branch.

No staging was performed while preparing this plan.

Current branch:

- `codex/adh-local-predeploy-package`

## Recommended Route

Use the source snapshot route first. Treat generated public assets as a separate decision.

Reason:

- The core source snapshot has 371 changed/untracked entries in the selected source groups.
- The public asset group has 26 changed/untracked entries, including generated Filament assets
  and `public/sitemap.xml`.
- `public/sitemap.xml` should not be staged by default.
- `get([` and `where(` are accidental local artifacts and must remain unstaged.

## Route A - Source Snapshot Staging

Use this route if the remote target branch does not already contain the ADH application
baseline.

Proposed command:

```bash
git add \
  .env.example \
  .env.production.example \
  composer.json composer.lock \
  package.json package-lock.json \
  phpunit.xml \
  postcss.config.js tailwind.config.js vite.config.js \
  bootstrap \
  config \
  app \
  database/migrations \
  database/seeders \
  lang \
  routes \
  resources \
  tests \
  docs/reports
```

Then stage intentional deletions if confirmed:

```bash
git rm public/robots.txt resources/views/welcome.blade.php
```

Important:

- `database/database.sqlite` is ignored and must remain unstaged.
- `.env` is not included.
- `node_modules/`, `vendor/`, and `storage/` are not included.
- `get([`, `where(`, and `public/sitemap.xml` are not included.

## Route B - Runtime Public Asset Add-On

Use only if deployment will not publish/build Filament and static assets on the server.

Proposed command:

```bash
git add \
  public/images/branding \
  public/images/news \
  public/css/filament \
  public/js/filament
```

Do not include by default:

```bash
public/sitemap.xml
```

Reason:

- Sitemap should normally be generated by application command or deploy step.

## Required Review After Staging

After any staging route, run:

```bash
git diff --cached --name-only
git diff --cached --stat
git diff --cached --check
```

Review for:

- accidental local files,
- secrets,
- generated cache/runtime files,
- smoke test artifacts,
- unintended deletions.
