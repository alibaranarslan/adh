# ADH Generated Asset Ignore Policy - 2026-05-12

## Purpose

Record the cleanup applied after the local predeploy snapshot commits.

## Changes

Updated `.gitignore` to exclude generated public runtime outputs:

- `/public/css/filament`
- `/public/js/filament`
- `/public/sitemap.xml`

Deleted accidental local artifacts:

- `get([`
- `where(`

## Rationale

Generated Filament public assets should be produced/published during deployment or dependency
setup, not mixed into the source snapshot by default.

`public/sitemap.xml` should be generated by `php artisan sitemap:generate`, which is already
part of the scheduled production command set.

The deleted root files contained PHP command-line parse error output and were not release
artifacts.

## Remaining Untracked Files

The following groups remain intentionally untouched:

- root audit/triage markdown files,
- `handoff/03-quality/release-audit/`.

These should be either migrated into `docs/reports/` in a future documentation pass or left
outside the release branch.

## Deploy Note

Hetzner deployment should include:

```bash
php artisan sitemap:generate
```

Filament assets should be published/generated using the correct command for the installed
Filament version if the package install step does not already provide them.
