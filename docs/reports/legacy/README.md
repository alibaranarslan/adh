# ADH Legacy Reports

This directory keeps historical audit and IHA recovery handoff documents that are useful as
forensic context but are not part of the runtime application.

## Directories

- `release-audit/`: early public/admin audit, defect triage, and release-gate notes.
- `iha-recovery/`: historical IHA recovery diagnosis, execution, verification, and runtime
  evidence documents.

## Policy

These files are preserved for context. Current readiness decisions should rely on the newer
dated reports in `docs/reports/`.
